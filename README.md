# PresPPTDeck

咨询式 PPT 内容策划 v2：把业务资料整理为可制作的逐页内容稿，包含咨询叙事、证据检查和蓝白商务视觉规范。生成 PPT 文件时，配合演示文稿工具。

## 在 Codex 中加载

请将仓库根目录的 `SKILL.md` 和完整的 `references/` 放入 `~/.codex/skills/consulting-ppt-content-v2/`。重新开始一轮对话，输入 `$consulting-ppt-content-v2` 调用。也可让 Codex 使用 skill-installer 从本仓库的 `main` 分支安装根路径 `.`，安装名称设为 `consulting-ppt-content-v2`。

- [Skill 入口](SKILL.md)
- [默认视觉规范](references/default-visual-style.md)
- [变更记录](CHANGELOG.md)

旧版可从 Git 历史查阅。
