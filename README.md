# PresPPTDeck

> AI-powered Business Presentation Consultant Skill

PresPPTDeck is an AI Skill designed to help professionals create high-quality business presentations.

It transforms:
- Business ideas
- Project information
- Strategic plans

into:
- Presentation logic
- Slide architecture
- Visual design suggestions
- PPT generation plans
- Presentation coaching

Core principle:

> Think first, express second; logic first, design second; persuasion first, decoration second.


## Core Workflow

PresPPTDeck follows the 12-step presentation methodology:

1. Define audience
2. Define purpose
3. Identify key concerns
4. Build storyline
5. Design slide structure
6. Select visual style
7. Select visual model
8. Review Markdown logic
9. Confirm output format
10. Collect resources
11. Generate PPT
12. Presentation coaching

- Annual review

- Product strategy
