# Design Style System — 设计风格系统

> 5种完整视觉规范，从 assets/design_styles.md 进化而来。每种风格包含完整的配色、字体、图标方案，可直接用于PPT制作。

---

## 风格选择规则

AI 根据汇报对象和行业自动匹配：

| 汇报对象 | 行业 | 推荐风格 |
|---------|------|---------|
| 老板/管理层 | 金融/投资 | 金融黑金 |
| 老板/管理层 | 科技/互联网 | 科技蓝白 |
| 老板/管理层 | 通用 | 极简白灰 |
| 客户 | 通用 | 科技蓝白 |
| 投资人 | 通用 | 金融黑金 |
| 团队内部 | 通用 | 极简白灰 |
| 产品发布 | 通用 | 活力橙红 或 深色科技 |
| 技术评审 | 通用 | 科技蓝白 |

---

## 1. 科技蓝白

**设计理念：** 专业、可信、前沿，适合技术型汇报。

**配色方案：**

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | #1A73E8 | 标题、重点元素、图表主色 |
| 主色深 | #0D47A1 | 标题强调、深色背景 |
| 主色浅 | #E8F0FE | 浅色背景、卡片底色 |
| 辅色 | #4285F4 | 二级标题、次要图表 |
| 强调色 | #FF6D00 | 关键数据、行动号召 |
| 强调绿 | #0F9D58 | 正向数据、完成状态 |
| 强调红 | #DB4437 | 负面数据、警示信息 |
| 背景白 | #FFFFFF | 页面主背景 |
| 背景灰 | #F8F9FA | 卡片背景、分区背景 |
| 文字黑 | #202124 | 正文 |
| 文字灰 | #5F6368 | 辅助说明 |
| 分割线 | #DADCE0 | 分割线、边框 |

**字体：** 标题 思源黑体 Bold / 正文 思源黑体 Regular
**图标：** Material Icons 风格，线性图标
**适合：** AI、技术、数字化、产品汇报

**配色方案：**

| 角色 | 色值 | 用途 |

| 辅色 | #4A4A6A | 二级信息 |
