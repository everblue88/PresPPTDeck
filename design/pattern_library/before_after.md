# Pattern: Before/After（改造前后）

## 适用场景

- 展示改进前后的对比
- 效果展示、优化成果、版本升级

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ┌────────────────┐  ┌────────────────┐  │
│  │   BEFORE       │  │   AFTER        │  │
│  │                │  │                │  │
│  │  • 问题1       │→│  • 改进1       │  │
│  │  • 问题2       │  │  • 改进2       │  │
│  │  • 问题3       │  │  • 改进3       │  │
│  │                │  │                │  │
│  │  [指标: 差]    │  │  [指标: 好]    │  │
│  └────────────────┘  └────────────────┘  │
│        灰色调              彩色           │
│                                          │
│  核心变化：[效率提升XX% / 指标改善XX%]    │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| BEFORE卡片 | 左半 | 灰色调，展示问题 |
| AFTER卡片 | 右半 | 彩色，展示改进 |
| 中间箭头 | 两卡片之间 | → 或 大箭头 |
| 核心变化 | 底部 | 一句话总结+数据 |

## 内容模板

```
标题：[对比主题]

BEFORE — [问题状态]
  - 问题1
  - 问题2
  - 问题3
  关键指标：[数值]

AFTER — [改进状态]
  - 改进1
  - 改进2
  - 改进3
  关键指标：[数值]

核心变化：[一句话总结 + 数据]
```

## 使用示例

```
标题：AI赋能前后：运营效率对比

BEFORE — 传统模式
  - 运营剪辑依赖人工，耗时2小时/条
  - 业务专家知识分散，难以复用
  - 重复性工作占工作量的60%

AFTER — AI增强模式
  - 运营剪辑效率提升50%，1小时/条
  - AI提炼专家知识，形成知识库
  - 自动化流程释放40%人力

核心变化：AI赋能后，运营效率提升50%
```

## 视觉评分要点

- BEFORE使用灰色调，AFTER使用彩色
- 对比点数量一致（3-4个）
- 核心变化数据突出显示
- 箭头或过渡元素清晰
