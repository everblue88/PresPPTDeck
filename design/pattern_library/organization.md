# Pattern: Organization（组织架构）

## 适用场景

- 展示团队结构、角色分工
- 团队介绍、项目组织、公司架构

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│              ┌──────────┐                │
│              │ 负责人    │                │
│              └─────┬────┘                │
│                    │                     │
│      ┌─────────────┼─────────────┐       │
│      │             │             │       │
│  ┌───┴───┐    ┌───┴───┐    ┌───┴───┐   │
│  │ 团队A  │    │ 团队B  │    │ 团队C  │   │
│  │ 5人    │    │ 3人    │    │ 4人    │   │
│  └───────┘    └───────┘    └───────┘   │
│                                          │
│  团队A：[职责]                            │
│  团队B：[职责]                            │
│  团队C：[职责]                            │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 架构图 | 中部 | 树形结构 |
| 节点 | 层级排列 | 矩形，含名称+人数 |
| 连接线 | 层级之间 | 直线或折线 |
| 职责说明 | 底部 | 12-14pt |

## 内容模板

```
标题：[组织/团队名称]

负责人：[姓名/角色]

直接下属：
  - 团队A：[名称] — [人数]人 — [职责]
  - 团队B：[名称] — [人数]人 — [职责]
  - 团队C：[名称] — [人数]人 — [职责]

（可选）虚线汇报/协作关系
```

## 使用示例

```
标题：AI产研团队组织结构

负责人：AI产品总监

直接下属：
  - AI产品团队：5人 — 产品规划、需求分析、用户研究
  - AI工程团队：8人 — 模型开发、平台建设、工程实现
  - AI运营团队：3人 — 知识沉淀、模型运营、效果评估

总计：17人，覆盖AI产研全链路
```
