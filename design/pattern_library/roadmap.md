# Pattern: Roadmap（路线图）

## 适用场景

- 展示未来规划、分阶段目标
- 战略规划、产品规划、年度计划

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ┌────────────────┐                      │
│  │  Phase 1       │──→                   │
│  │  H1 2026       │                      │
│  │  • 目标1       │                      │
│  │  • 目标2       │                      │
│  └────────────────┘                      │
│         ↓                                │
│  ┌────────────────┐                      │
│  │  Phase 2       │──→                   │
│  │  H2 2026       │                      │
│  │  • 目标1       │                      │
│  │  • 目标2       │                      │
│  └────────────────┘                      │
│         ↓                                │
│  ┌────────────────┐                      │
│  │  Phase 3       │                      │
│  │  2027          │                      │
│  │  • 目标1       │                      │
│  └────────────────┘                      │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 阶段卡片 | 由上到下排列 | 等宽，间距0.2英寸 |
| 连接箭头 | 卡片之间 | 向下箭头 |
| 每个卡片 | 左对齐 | 含阶段名+时间+目标 |

## 内容模板

```
标题：[路线图主题]

Phase 1：[时间范围]
  - [目标1]
  - [目标2]
  - [目标3]

Phase 2：[时间范围]
  - [目标1]
  - [目标2]

Phase 3：[时间范围]
  - [目标1]
  - [目标2]
```

## 使用示例

```
标题：2026年规划：全面深化三大方向

Phase 1：H1 2026 — 夯实基础
  - 决策圈APP用户突破5,000
  - AI自动化覆盖5个业务场景
  - 数据体系接入全业务线

Phase 2：H2 2026 — 加速突破
  - 推出首个AI付费产品
  - 新客获取渠道建成
  - 付费转化率提升至15%

Phase 3：2027 — 规模复制
  - APP用户突破10,000
  - AI产品线扩充至3个
  - 团队规模扩大至50人
```
