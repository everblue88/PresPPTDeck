# Pattern: Timeline（时间轴）

## 适用场景

- 展示时间节点、里程碑
- 历史回顾、项目进度、发展历程

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ●──────────●──────────●──────────●      │
│  │          │          │          │      │
│  Q1         Q2         Q3         Q4     │
│  里程碑1    里程碑2    里程碑3    里程碑4   │
│  说明       说明       说明       说明     │
│                                          │
└──────────────────────────────────────────┘
```

### 变体：上下交替

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ●──────────●──────────●──────────●      │
│  │  说明     │          │  说明    │      │
│  │  Q1       │  Q2      │  Q3      │Q4   │
│       │  说明     │          │  说明  │    │
│       ●──────────●──────────●────────●    │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 时间轴线 | 水平中线 | 2pt粗线 |
| 节点 | 均匀分布 | 圆形，8-12pt直径 |
| 节点标签 | 节点上方/下方 | 日期+事件 |
| 说明文字 | 标签下方 | 12-14pt |

## 内容模板

```
标题：[时间轴主题]

节点1：[时间] — [事件名称]
  说明：[一句话描述]

节点2：[时间] — [事件名称]
  说明：[一句话描述]

节点3：[时间] — [事件名称]
  说明：[一句话描述]

节点4：[时间] — [事件名称]
  说明：[一句话描述]
```

## 使用示例

```
标题：2025年产品发展历程

Q1：决策圈APP V1.0 上线
  完成核心功能链路，支持注册和基础服务

Q2：V1.5 体验优化
  优化用户操作链路，降低使用门槛

Q3：V2.0 付费功能上线
  开通付费会员体系，首月转化率8%

Q4：AI能力集成
  接入AI投研功能，运营效率提升50%
```
