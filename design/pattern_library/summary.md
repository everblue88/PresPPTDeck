# Pattern: Summary（执行摘要）

## 适用场景

- 在封面之后，用1页讲清楚整个汇报的核心
- 让听众在30秒内理解全貌

## 结构图示

```
┌──────────────────────────────────────────┐
│  执行摘要                                 │
│                                          │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │ 核心结论  │ │ 关键数据  │ │ 行动号召  │ │
│  │          │ │          │ │          │ │
│  │ 一句话   │ │ 3-4个   │ │ 期望的   │ │
│  │ 总结     │ │ 核心指标 │ │ 决策/行动│ │
│  └──────────┘ └──────────┘ └──────────┘ │
│                                          │
│  ┌──────────────────────────────────────┐│
│  │  关键发现 / 核心洞察                 ││
│  │  • 要点1                             ││
│  │  • 要点2                             ││
│  └──────────────────────────────────────┘│
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 大小 |
|------|------|------|
| 标题 | 左上 | 28pt |
| 三栏卡片 | 标题下方 | 等宽，高度约2.5英寸 |
| 底部要点 | 卡片下方 | 全宽，高度约1.5英寸 |

## 内容模板

```
标题：执行摘要

卡片1 — 核心结论
  [一句话总结整个汇报的核心信息]

卡片2 — 关键数据
  • 指标1: [数值]
  • 指标2: [数值]
  • 指标3: [数值]

卡片3 — 行动号召
  [期望听众做什么]

底部要点：
  • 关键发现1
  • 关键发现2
```

## 使用示例

```
标题：执行摘要

卡片1：核心结论
  2025年完成决策圈APP从0到1，AI效率提升50%，数据体系覆盖全流程

卡片2：关键数据
  • 注册用户：3,691人
  • 日活：777
  • AI效率：+50%

卡片3：行动号召
  期望获得CTO认可，授予更多项目主导权

底部要点：
  • 新客增长是2026年核心命题
  • AI金融产品是下一个突破点
```
