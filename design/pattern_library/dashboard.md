# Pattern: Dashboard（数据仪表盘）

## 适用场景

- 展示核心指标、KPI数据
- 数据汇报、成果展示、绩效回顾

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │ 指标名称  │ │ 指标名称  │ │ 指标名称  │ │
│  │          │ │          │ │          │ │
│  │  3,691   │ │   777    │ │  50%     │ │
│  │          │ │          │ │          │ │
│  │  ↑15%    │ │  ↑20%    │ │  ↑50%    │ │
│  └──────────┘ └──────────┘ └──────────┘ │
│                                          │
│  ┌──────────┐ ┌──────────┐              │
│  │ 指标名称  │ │ 指标名称  │              │
│  │          │ │          │              │
│  │  61.3%   │ │  1,429   │              │
│  │          │ │          │              │
│  │  服务注册 │ │ 待转化    │              │
│  └──────────┘ └──────────┘              │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 指标卡 | 均匀分布 | 一行3-4个，可多行 |
| 卡片内 | 居中 | 指标名+数值+趋势 |

## 指标卡模板

```
指标名称：[14pt，灰色]
数值：[36pt，加粗，黑色]
趋势：[14pt，绿色↑/红色↓]
说明：[12pt，灰色，可选]
```

## 内容模板

```
标题：[数据总结，有观点]

指标卡1：
  名称：[指标名称]
  数值：[核心数字]
  趋势：[↑/↓ + 百分比]
  说明：[一句话]

指标卡2：
  ...

指标卡3：
  ...

指标卡4：
  ...
```

## 使用示例

```
标题：决策圈APP核心数据

指标卡1：总注册用户
  数值：3,691
  趋势：含服务注册2,262人

指标卡2：日活跃用户
  数值：777
  趋势：DAU稳定

指标卡3：服务注册率
  数值：61.3%
  趋势：2,262 / 3,691

指标卡4：待转化用户
  数值：1,429
  趋势：无服务注册，待激活空间
```
