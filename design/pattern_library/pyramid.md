# Pattern: Pyramid（金字塔）

## 适用场景

- 层级关系、优先级排序
- 战略拆解、能力分层、需求优先级

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│              /\
│             /愿景\                        │
│            /──────\                       │
│           / 战略   \                      │
│          /──────────\                     │
│         /   目标     \                    │
│        /──────────────\                   │
│       /    执行计划    \                  │
│      /──────────────────\                 │
│     /      基础支撑       \               │
│    /────────────────────────\             │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 金字塔 | 中部 | 居中，占总面积60-70% |
| 每层标签 | 层内居中 | 层名+说明 |
| 说明文字 | 右侧或底部 | 每层详细说明 |

## 内容模板

```
标题：[金字塔主题]

顶层（1个）：[愿景/核心目标]
  - 一句话说明

第二层（2-3个）：[战略/关键策略]
  - 策略1
  - 策略2

第三层（3-5个）：[目标/举措]
  - 举措1
  - 举措2
  - 举措3

底层：[基础支撑]
  - 资源、团队、平台
```

## 使用示例

```
标题：AI战略金字塔

顶层：成为AI驱动的金融科技领导者

第二层（3大战略）：
  - AI产品化：打造可付费的AI金融产品
  - AI赋能业务：用AI提升现有业务效率
  - AI能力建设：建立AI人才和技术底座

第三层（关键举措）：
  - AI客服、AI投研、AI风控
  - 自动流程、知识沉淀
  - 人才引进、平台建设

底层：算力资源 + 数据治理 + 安全合规
```

## 视觉评分要点

- 层级不超过5层
- 每层内容简洁（不超过3个要点）
- 顶层最突出（视觉重心）
- 颜色从上到下由深变浅
