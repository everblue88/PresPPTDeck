# Pattern: Matrix（矩阵/四象限）

## 适用场景

- 多维度分析、定位分析
- 优先级排序、策略选择、竞争力分析

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│       高 ↑                                │
│       │   第二象限      第一象限           │
│  维度2│   [策略B]       [策略A]           │
│       │                                  │
│       │   第三象限      第四象限           │
│       │   [策略D]       [策略C]           │
│       低                                 │
│       低 ←────── 维度1 ──────→ 高        │
│                                          │
│  推荐：聚焦第一象限                        │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 矩阵 | 中部 | 正方形，约5英寸 |
| 坐标轴 | 矩阵中 | X轴+Y轴，带标签 |
| 象限标签 | 四角 | 策略建议 |
| 数据点 | 矩阵内 | 圆形气泡，标注名称 |

## 内容模板

```
标题：[分析主题]

维度1：[X轴名称]（低→高）
维度2：[Y轴名称]（低→高）

象限分布：
  第一象限（高-高）：[策略/项目] — 优先投入
  第二象限（低-高）：[策略/项目] — 选择性投入
  第三象限（低-低）：[策略/项目] — 暂缓或淘汰
  第四象限（高-低）：[策略/项目] — 优化效率

结论：[基于矩阵的决策建议]
```

## 使用示例

```
标题：AI应用场景优先级矩阵

维度1：业务价值（低→高）
维度2：技术可行性（低→高）

象限分布：
  第一象限（高价值-高可行）：AI客服、AI投研 → 优先投入
  第二象限（低价值-高可行）：AI流程自动化 → 选择性投入
  第三象限（低价值-低可行）：AI风控模型 → 暂缓
  第四象限（高价值-低可行）：AI交易策略 → 联合研发

结论：H1聚焦AI客服和AI投研两个场景
```
