# 默认视觉规范：蓝白商务数据可视化风格

## 适用与优先级

本规范用于本 skill 产出的 PPT 制作提示词，也适用于同一内容方案延伸的 HTML、信息图、数据报告与看板交接。它不将内容 skill 扩展为渲染工具，也不修改其他 skill 或全局设置。

- 用户未指定样式：自动采用本规范，无需先询问配色。
- 用户当次提供品牌规范、模板、参考图或特殊要求：明确要求覆盖对应默认项，其余沿用本规范。多个当次要求互相冲突且无法判断时才澄清。
- 历史案例中的蓝紫渐变、3D 机器人或轻立体图标不是默认项；只有用户选择相应风格时采用。
- 事实、论证与阅读效率优先于模板。保留已批准内容；不为填满 KPI 卡片虚构数据，不为套叙事更改汇报目的。

本规范记录蓝白商务数据可视化的配色、版式、图表和制作要求。

## 视觉定位与配色

专业、清晰、现代、商务，具有克制的科技感。白底、深蓝标题、蓝色重点、浅蓝模块，接近企业经营分析与金融机构报告的表达。信息密度按现场讲述或会后阅读调整，保持关键论据充分、分组清楚，不靠密集小字增加丰富度。

| 用途 | 色值 | 使用规则 |
|---|---|---|
| 主背景 | `#FFFFFF` | 页面以白色为主 |
| 主标题、重要结论 | `#142B4A` | 深海军蓝、粗体 |
| 主色 | `#0875DF` | 模块标题、关键数字、图标、重点数据 |
| 辅助蓝 | `#35A4F5` | 次级强调与局部渐变 |
| 浅蓝背景 | `#EAF4FF` | 卡片、洞察区、流程节点 |
| 边框 | `#9BCBFF` | 细描边、分隔线 |
| 正文 | `#252D38` | 深灰色，保证阅读对比度 |
| 辅助文字 | `#64748B` | 注释、来源、坐标轴与次级说明 |

渐变仅用于标题装饰、结论横幅或局部强调；不整页铺满。圆角、边框、内边距、间距保持一致，阴影轻微。避免复杂纹理、高饱和大面积铺底、厚重金属与无意义装饰。状态色只表达真实状态：正向可用低饱和青绿，风险可用克制橙红；保留金融行情的明确颜色约定，并配文字/符号说明，不只靠颜色区分。

## 信息层级与图标

- 阅读顺序：**结论 → 关键数据/事实 → 原因解释 → 行动或含义**。每页一个主标题与核心焦点，模块标题、核心数字、正文、注释层次稳定。
- 中文采用清晰无衬线字体，如思源黑体、微软雅黑、苹方。数字同时标注指标名称、单位、时间与比较基准。正文使用短句与必要项目符号，来源和限制仍需可读。
- 字号按媒介和画布适配；手册的像素示意不是 PPT 的固定磅值。不得用缩小字号解决内容溢出，优先分组、改图解或将补充细节移到备注/附录；必要正文保留。
- 优先简洁 Outline 线性图标，蓝色单色或蓝色双色，搭配浅蓝圆角方形/圆形底板。同页同一套图标，尺寸、描边、视角与视觉重量统一。一个卡片通常一个有语义的图标，不用图标填空。
- 常用语义：趋势＝折线/箭头；负责人＝用户/团队；渠道＝平台/电脑；目标＝靶心；风险＝警告；动作＝工具/火箭；分析＝柱状图/烧杯；流程＝节点/连线。

## 按内容选择版式

| 版式 | 信息组织 | 适用内容 |
|---|---|---|
| A 总览型 | 顶部标题与必要副标题；中部约 3—4 个洞察卡片；下部关键指标或简图；底部一句话结论 | 管理层摘要、整体表现；卡片数量按真实内容调整 |
| B 数据分析型 | 左侧约 65% 主图，右侧约 35% 洞察；底部排名、口径或总结 | 趋势、渠道对比、结构拆解 |
| C 诊断决策型 | 上部问题/证据，下部逐项对应动作，结论横幅收口 | 诊断、风险、策略建议 |
| D 流程时间轴型 | 时间/阶段/步骤节点、连接线、阶段卡片，标注必要条件 | 项目推进、业务机制、依赖关系 |

PPT 与横版信息图默认 16:9，常用分栏、2×2 或 3×2 网格。桌面 HTML 可采用分栏，移动端转单列，表格必要时横向滚动；适配媒介而非复制固定坐标。

先确定读者任务，再选择图解。真实顺序才用流程箭头；并列应用用分组/矩阵，对比用同口径对照，层级用树或分层图，趋势用时间序列。逐页交接明确“对象、关系、阅读方向、必要标签和图例”；多类连线区分主流程、反馈或依赖，说明颜色/虚实含义。装饰连线不表示因果，不把并列能力画成已实现的技术流水线。

经营分析且用户未锁定大纲时，优先采用 **总览（发生什么）→拆解（问题在哪）→诊断（为什么）→行动（怎么做）**。项目成果、知识分享等按听众和目的选择叙事，不强制四阶段；样式要求不构成更改已批准大纲的授权。

## 图表与数据表达

- 折线图用于时间趋势，线宽统一、圆形节点清楚；点多时控制节点密度，保证趋势可读。类别对比用柱状图，重点项用核心蓝、其他项用同系浅色；排名可加数字徽章与重点值。
- 比较先统一对象、时间窗与口径，写清数量、金额、比例、百分点、同比与环比。小样本提示样本量；相关性不足以证明因果。
- 不同单位或悬殊量级优先分图/分面；需要双轴时明确单位与对应系列。柱状图通常从零起，截断轴须明确提示。图表不使用会歪曲数据的立体透视。
- 坐标轴、刻度、图例、数据标签与来源完整且不裁切；顶部预留标签空间，长类目换行或换横向图。图例避开数据，单系列无需冗余图例。
- 缺失值不画成零，不补造曲线；标为无数据/待补并说明影响。没有量化支撑时使用已知事实、机制、案例或定性对比，不生成装饰性“效果数据”。

## 交付检查

内容阶段检查提示词已包含有效风格、逐页图解关系与证据边界。制作阶段应检查：白底与蓝灰层级统一；模块和图标一致；主结论突出；数据名称/单位/基准齐全；来源和样本限制可读；零与缺失区分；坐标、图例和标签不裁切；流程关系真实；无正文溢出。实际生成文件后才能声称文件可打开或渲染正常；仅交内容稿时，不声称已完成制作验收。
