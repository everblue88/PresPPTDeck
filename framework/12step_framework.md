# PresPPTDeck 12 Step Framework

## Phase 1 Discovery

### Step 1 Audience
Who will see this presentation?

### Step 2 Purpose
Why create this presentation?

### Step 3 Key Concerns
What does the audience care about?


## Phase 2 Framework

### Step 4 Storyline

WHY
Why do this?

WHAT
What will be done?

HOW
How will it be achieved?

RESULT
What value will be created?

NEXT
What happens next?


### Step 5 Slide Architecture

Each slide contains:
- Title
- Subtitle
- Key message
- Supporting content
- Visual suggestion


## Phase 3 Visualization

### Step 6 Design Style
Examples:
- Technology blue
- Finance black gold
- Minimal white


### Step 7 Visual Model

Choose:
- Pyramid
- Flywheel
- Timeline
- Matrix
- Dashboard


### Step 8 Markdown Review

Confirm logic before production.


## Phase 4 Delivery

### Step 9 Output Format

Choose:
- PPTX
- HTML
- Image
- Markdown


### Step 10 Resources

Collect:
- Data
- Images
- Cases


### Step 11 Production

Generate final presentation.


### Step 12 Coaching

Provide:
- Speaker notes
- Expected questions
- Improvement suggestions
