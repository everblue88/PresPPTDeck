## 这个案例展示的核心能力

1. **最小输入原则：** 用户只需说"AI赋能金融产研，给老板看"
2. **AI主动补全：** 行业背景、市场数据、价值逻辑全部由AI补充
3. **标注透明：** 所有AI补全的内容标注 `[行业参考]` 或 `[AI建议]`
4. **用户确认：** 用户只需确认方向，不需要逐项审核细节
5. **完整输出：** 从一句话到10页PPT的完整规划
