# Content Checklist — 内容/证据层检查清单

对应 02 Content Strategist 输出的质量检查。

## Evidence Mapping
- [ ] 每个结论是否有论据？
- [ ] 每条论据是否有证据（数据/案例/Benchmark）？
- [ ] 掉可支撑关键判断时是否标记缺口？

## 数据诚实
- [ ] 是否虚构数据 / 案例 / 客户 / ROI？
- [ ] 缺失数据是否标记【待补】/【待验证】？
- [ ] 是否区分【用户事实】【外部事实】【行业判断】【建议】？

## So What
- [ ] 是否从 Finding 推进到 Insight 再到 Implication？
- [ ] 是否只堆 Facts 而无洞察？

## 内容密度
- [ ] 每页信息单元是否 ≥8？
- [ ] 是否有裸 Bullet / 裸数据 / 裸案例？
- [ ] 每个关键判断是否有对应证据？
- [ ] 是否避免 10 个平级 Bullet？

## Evidence 等级
- [ ] 是否标注 High / Medium / Low？
- [ ] 用户是否知道哪些结论最可靠？
