# Visual Checklist — 视觉层检查清单

对应 03 Visual Designer 输出的质量检查。

## Pattern 选择
- [ ] 是否先判断信息结构再选 Pattern？
- [ ] 是否遵循 Content → Structure → Pattern → Layout？
- [ ] 是否为了模板方便而套固定 Layout？

## 页面骨架
- [ ] 每页是否含 Title / Subtitle / Core Visual / Evidence / Bottom Takeaway？
- [ ] 主标题是否为 Action Title（结论句）？

## 信息图
- [ ] 关系/流程/因果/层级/闭环是否用图而非文字？
- [ ] 是否出现"标题 + 大段文字"？

## 网格与层级
- [ ] 是否遵循 12-column grid？
- [ ] 元素是否对齐？间距是否一致？
- [ ] 视觉层级是否清晰（Action Title → Section → Module → Body → Footnote）？

## 颜色 / 图标
- [ ] 颜色是否具有语义（绿=成功/橙=风险/灰=辅助）？
- [ ] 每页配色是否 ≤4 种？
- [ ] 图标是否统一风格/尺寸/线宽？

## 信息密度
- [ ] 页面有效内容区域是否 ≥60%？
- [ ] 是否制造无意义大面积空白？

## 可编辑性
- [ ] 核心信息是否可编辑（文字/图形/表格/图表）？
- [ ] 是否把整页渲染成图片（禁止）？
