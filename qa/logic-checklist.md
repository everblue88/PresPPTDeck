# Logic Checklist — 逻辑层检查清单

对应 01 Logic Architect 输出的质量检查。

## Governing Question
- [ ] 是否形成了明确的核心问题？
- [ ] 问题是否可被回答、可落地到决策？

## Issue Tree / MECE
- [ ] 一级分支是否 3-5 个？
- [ ] 分支是否互斥（无重叠）？
- [ ] 分支是否完整（无遗漏）？
- [ ] 层级是否清晰（无混乱）？

## Hypothesis
- [ ] 每个核心问题是否有假设？
- [ ] 是否区分了 Fact / Hypothesis / Assumption？

## Storyline
- [ ] 是否形成完整逻辑递进（Because → Therefore → So What → Now What）？
- [ ] 页面标题单独连读，能否形成完整摘要？
- [ ] 是否有 Section Conclusion？

## Executive Summary
- [ ] 是否压缩为 1 个核心结论 + 3-5 个支撑结论？

## 越界检查
- [ ] 是否讨论视觉 / 配色 / 布局？（应该没有）
