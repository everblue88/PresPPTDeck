# PPT视觉模型库

> 每种视觉模型包含：适用场景、结构说明、使用建议、搭配指南。

---

## 1. 金字塔模型

### 适用场景
- 战略拆解（从愿景到执行）
- 能力分层（从基础到高级）
- 优先级排序（从重要到次要）
- 组织架构（从高层到基层）

### 结构说明
```
        /\
       /顶层\
      /------\
     /第二层  \
    /----------\
   /第三层      \
  /--------------\
 /基础层          \
/__________________\
```

### 使用建议
- 顶层放核心结论或最高战略
- 每层最多3个要点，保持简洁
- 从下往上读是"支撑关系"，从上往下读是"拆解关系"
- 配色：从深到浅（深色在顶层）或从暖到冷

### 搭配指南
- 与"分层模型"结合：金字塔每层可展开为分层模型
- 与"图标卡片"结合：每层用图标+文字表达

### 最佳实践
- 战略汇报：使命→愿景→战略→目标→行动
- 能力建设：基础能力→专业能力→核心能力→差异化能力
- 产品架构：基础设施→数据层→业务层→应用层→用户层

## 2. 四象限/矩阵

### 适用场景
- 市场定位分析
- 能力评估矩阵
- 优先级排序
- SWOT分析
- 竞品分析

### 结构说明
```
       高
       │
  第二象限 │ 第一象限
  （改进区） │ （优势区）
       │
  ──────┼──────→ 高
       │
  第三象限 │ 第四象限
  （观察区） │ （待发展区）
       │
       低
```

### 使用建议
- X轴和Y轴的标签要清晰（是什么 vs 什么）
- 每个象限用不同颜色区分
- 气泡大小可表达第三个维度（如市场规模）
- 第一象限（右上）是重点，用强调色突出

### 搭配指南
- 与"卡片"结合：每个象限放一个要点卡片
- 与"箭头"结合：展示从当前象限到目标象限的移动方向

### 最佳实践
- 市场分析：市场增长率(Y) × 市场份额(X)
- 能力评估：业务价值(Y) × 实施难度(X)
- 优先级：影响力(Y) × 投入成本(X)

## 3. 流程图

### 适用场景
- 业务流程展示
- 决策路径说明
- 系统交互流程
- 用户旅程

### 结构说明
```
[开始] → [步骤1] → [步骤2] → [步骤3] → [结果]
            │                      │
            ↓                      ↓
        [分支A]              [子步骤]
            │
            ↓
        [合并]
```

### 使用建议
- 横向流程：从左到右，适合3-5步
- 纵向流程：从上到下，适合5步以上
- 泳道图：不同角色/部门分轨道展示
- 关键节点用不同颜色标注

### 搭配指南
- 与"时间轴"结合：带时间节点的流程
- 与"图标"结合：每步用图标快速识别

### 最佳实践
- 用户旅程：发现→了解→试用→购买→使用→推荐
- 决策流程：收集信息→分析→评估→决策→执行→复盘
- 开发流程：需求→设计→开发→测试→发布→运维

## 4. 时间轴

### 适用场景
- 项目里程碑
- 产品路线图
- 公司发展历程
- 季度/年度规划

### 结构说明
```
────●──────────●──────────●──────────●────→
    │          │          │          │
   Q1         Q2         Q3         Q4
  事件1      事件2      事件3      事件4
```

### 使用建议
- 横向时间轴：适合展示时间序列（从左到右）
- 纵向时间轴：适合展示里程碑详情（从上到下）
- 节点大小表达重要性：大节点=关键里程碑
- 已完成和未完成用不同颜色区分（实心/空心）

### 搭配指南
- 与"卡片"结合：每个节点展开为详细卡片
- 与"泳道图"结合：多轨道并行时间轴

### 最佳实践
- 项目计划：Q1目标→Q2目标→Q3目标→Q4目标
- 产品路线图：V1.0→V1.5→V2.0→V3.0
- 公司历程：2018年创立→2020年A轮→2022年B轮→2024年盈利

## 5. 飞轮模型

### 适用场景
- 增长飞轮
- 持续改进循环
- 生态闭环
- 正向循环机制

### 结构说明
```
     ┌──────────┐
     │  更多用户  │
     ↓          ↑
┌─────────┐  ┌─────────┐
│ 更好体验  │  │ 更多内容  │
└─────────┘  └─────────┘
     ↑          ↓
     │  更多投入  │
     └──────────┘
```

### 使用建议
- 3-5个节点，太多会显得复杂
- 节点之间用弯曲箭头连接，形成闭环
- 每个节点放一个核心指标
- 飞轮中心放最终目标或核心KPI

### 搭配指南
- 与"数据指标"结合：每个节点标注关键数据
- 与"分层模型"结合：飞轮外围展示支撑层

### 最佳实践
- 增长飞轮：更多用户→更多内容→更好体验→更多用户
- 学习循环：实践→反思→总结→提升→实践
- 产品循环：用户反馈→产品改进→用户满意度提升→更多反馈

## 6. Before/After 对比

### 适用场景
- 效果展示（使用前 vs 使用后）
- 方案对比（旧方案 vs 新方案）
- 版本演进（旧版本 vs 新版本）
- 问题解决（问题 vs 解决方案）

### 结构说明
```
┌─────────────────┐     ┌─────────────────┐
│    BEFORE       │     │     AFTER       │
│                 │     │                 │
│  [问题描述]     │ ──→ │  [改进结果]     │
│  [旧数据]       │     │  [新数据]       │
│  [旧流程]       │     │  [新流程]       │
│                 │     │                 │
│  灰色/冷色调    │     │  彩色/暖色调    │
└─────────────────┘     └─────────────────┘
```

### 使用建议
- Before用灰色/冷色调，After用彩色/暖色调
- 中间用箭头或分隔线
- 对比点要一一对应（同样的指标，不同的值）
- 数据变化用百分比或绝对值标注

### 搭配指南
- 与"数据卡片"结合：放核心对比数据
- 与"流程图"结合：展示流程改造前后

### 最佳实践
- 效率提升：处理时间从30分钟→3分钟（90%提升）
- 成本降低：月成本从50万→30万（40%降低）
- 体验改善：用户满意度从3.2→4.8（50%提升）

## 7. Dashboard/指标卡

### 适用场景
- KPI展示
- 经营数据概览
- 项目核心指标
- 季度/年度数据总结

### 结构说明
```
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│ 指标1   │ │ 指标2   │ │ 指标3   │ │ 指标4   │
│        │ │        │ │        │ │        │
│ 5,230  │ │  89%   │ │  ¥3.2M │ │  +12%  │
│ 用户数   │ │ 满意度  │ │  收入   │ │  增长   │
│ ↑15%   │ │  ↑3%   │ │  ↑22%  │ │  ↑8%   │
└────────┘ └────────┘ └────────┘ └────────┘
```

### 使用建议
- 一页放4-6个指标卡，不要超过8个
- 每个卡片：图标 + 数字 + 标签 + 趋势
- 数字要大到能一眼看清（字号≥36pt）
- 趋势用颜色区分：绿色=好，红色=差

### 搭配指南
- 与"图表"结合：指标卡+详细趋势图
- 与"对比"结合：当前值 vs 目标值 vs 上期值

### 最佳实践
- 经营看板：GMV、用户数、订单量、客单价、转化率
- 项目看板：进度、预算使用率、完成率、风险数
- 团队看板：人数、产出、效率、满意度

## 8. 分层模型

### 适用场景
- 技术架构
- 能力建设体系
- 产品功能架构
- 组织能力分层

### 结构说明
```
┌─────────────────────────────────┐
│          应用层 / 表现层          │
├─────────────────────────────────┤
│          业务层 / 逻辑层          │
├─────────────────────────────────┤
│          数据层 / 服务层          │
├─────────────────────────────────┤
│          基础层 / 设施层          │
└─────────────────────────────────┘
```

### 使用建议
- 从下到上：基础层→应用层，表达"支撑关系"
- 每层用不同颜色，颜色从深到浅
- 每层放2-3个关键模块或能力
- 层与层之间的箭头说明依赖关系

### 搭配指南
- 与"金字塔"结合：分层模型是金字塔的横向展开
- 与"图标"结合：每层的模块用图标表示

### 最佳实践
- AI能力：基础设施→数据平台→模型服务→AI应用→业务场景
- 产品架构：数据层→中台服务→业务模块→用户界面
- 组织能力：基础管理→专业能力→业务理解→战略思维→领导力

## 9. 柱状图/条形图

### 适用场景
- 数值对比（不同类别、不同时间）
- 排名展示
- 构成分析（堆叠柱状图）
- 目标 vs 实际对比

### 使用建议
- 柱子数量≤8个，太多用条形图（横向）
- 柱子颜色不超过3种
- 数据标签放在柱子顶部
- Y轴从0开始（避免视觉误导）
- 关键数据用强调色突出

### 最佳实践
- 季度收入对比：Q1/Q2/Q3/Q4 并排
- 部门业绩排名：A→G部门横向条形图
- 预算构成：人力/技术/营销/运营 堆叠图

---

## 10. 折线图/趋势图

### 适用场景
- 时间趋势（月度/季度/年度）
- 多指标对比趋势
- 增长曲线
- 预测 vs 实际

### 使用建议
- 线条≤4条，太多难以区分
- 不同线条用明显不同的颜色
- 关键转折点标注事件
- 预测部分用虚线
- 图例放在图表下方或右侧

### 最佳实践
- 用户增长：月活用户12个月趋势
- 收入趋势：实际收入 vs 目标收入 vs 去年同期
- 多指标对比：收入增长率、用户增长率、利润率三条线

---

## 11. 饼图/环形图

### 适用场景
- 占比展示（市场份额、预算分配）
- 构成分析（用户来源、收入构成）

### 使用建议
- 切片≤6个，超过6个用"其他"合并
- 从12点钟方向开始，按大小顺时针排列
- 环形图中间可放总数
- 最大切片用主色，其他用辅色
- 不要用3D饼图（变形严重）

### 最佳实践
- 市场份额：我们 vs 竞品A vs 竞品B vs 其他
- 预算分配：研发40% / 营销30% / 运营20% / 其他10%
- 用户来源：自然流量 / 付费投放 / 推荐 / 其他

## 12. 图标卡片

### 适用场景
- 核心能力展示
- 关键优势列举
- 总结页面
- 服务/产品介绍

### 结构说明
```
┌────────┐  ┌────────┐  ┌────────┐
│  [图标]  │  │  [图标]  │  │  [图标]  │
│        │  │        │  │        │
│  标题1  │  │  标题2  │  │  标题3  │
│        │  │        │  │        │
│  描述   │  │  描述   │  │  描述   │
└────────┘  └────────┘  └────────┘
```

### 使用建议
- 每行3-4个卡片
- 图标 + 标题 + 一行描述
- 卡片之间间距相等
- 图标颜色统一，与整体风格一致

### 最佳实践
- 核心优势：技术领先、团队专业、服务优质、数据驱动
- 总结页：3个核心结论 + 1个行动号召
- 产品特性：快速、安全、易用、可扩展

## 页面视觉节奏建议

一个好的PPT应该像音乐一样有节奏变化：

```
封面：居中大标题（静止）
  ↓
目录：图标卡片（平稳）
  ↓
背景：数据冲击（冲击）
  ↓
策略：金字塔（结构）
  ↓
方案：分层模型（结构）
  ↓
过程：时间轴（流动）
  ↓
成果：Dashboard（数据高潮）
  ↓
规划：路线图（展望）
  ↓
总结：图标卡片（回归）
  ↓
感谢：简洁文字（收尾）
```

**原则：** 相邻页面避免连续使用同一种视觉模型，保持视觉新鲜感。
