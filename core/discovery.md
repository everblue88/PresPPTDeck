# Discovery — 信息采集

## 设计原则

> **核心问题必须回答，可选信息用户可跳过。AI负责理解20%，补全80%。**

Discovery 模块分为两层：**3个核心问题（必须）** + **可选信息（可跳过）**。用户可以直接回复"开始"跳过所有可选项。

---

## 第一层：核心问题（必须回答）

### Q1：汇报对象（必须）

> 这份汇报主要给谁看？

| 对象类型 | 关注点 | AI自动推断的汇报策略 |
|---------|--------|-------------------|
| 老板/管理层 | 战略价值、业务结果、资源效率 | 结论先行，讲"为什么"和"值不值" |
| 客户/甲方 | 解决方案、价值交付、ROI | 以客户视角，讲"解决什么问题"和"带来什么价值" |
| 投资人 | 市场规模、增长潜力、竞争壁垒 | 数据+故事，讲"为什么投"和"回报预期" |
| 团队内部 | 目标清晰度、任务分配、协作方式 | 行动导向，讲"做什么"和"怎么做" |
| 混合角色 | 需识别主要决策者 | 以主要决策者视角为主，兼顾其他角色 |

### Q2：汇报目的（必须）

> 希望通过这次汇报达成什么？

| 目的类型 | AI自动推断的故事线倾向 |
|---------|---------------------|
| 汇报成果/述职 | 强调"做了什么→取得什么成果→证明什么价值" |
| 争取资源 | 强调"为什么需要→投入多少→回报多少→不投的代价" |
| 推动项目/决策 | 强调"背景变化→核心问题→方案选择→为什么选这个" |
| 证明价值 | 强调"问题→方案→数据→价值" |
| 方案评审 | 强调"方案对比→优劣分析→推荐理由→风险应对" |
| 复盘总结 | 强调"预期→实际→差距→原因→改进" |

### Q3：核心输入（必须，自由文本）

> 请提供已有信息，可以是不完整的。例如：项目名称、几个关键词、已有材料、目标想法。

**示例输入：**
- "AI赋能金融产研"
- "做了一年的APP，想汇报成果"
- "今年做了三个项目：用户增长、体验优化、AI客服"

---

## 第二层：可选信息（可跳过，AI自动补全）

**在核心问题之后，展示以下可选项。用户可填可不填，不填的由AI自动补全。用户可以直接回复"开始"跳过所有可选项。**

| 可选信息 | 说明 | 示例 | AI默认行为 |
|---------|------|------|-----------|
| 汇报时长 | 5/10/15/30分钟 | "15分钟" | 默认15分钟，根据对象调整 |
| 设计风格偏好 | 5种风格 | "金融黑金" | 根据对象+行业自动匹配 |
| 核心数据 | 已有指标数据 | "日活777，跟单率8%" | 基于行业常识补充 |
| 竞品/对标信息 | 关注的竞品 | "对标XX期货APP" | 基于行业补充标杆案例 |
| 已有材料 | 参考文档 | "有份月度报告" | 不依赖，AI自行构建 |
| 特殊要求 | 必须包含/排除 | "一定要讲AI数字人" | 不添加特殊约束 |

### 交互示例

```
核心问题：
Q1: 给谁看？→ 老板/CTO
Q2: 什么目的？→ 年中述职
Q3: 核心输入？→ 做了APP、AI赋能、数据报告

可选信息（回复"开始"跳过，AI自动补全）：
- 汇报时长？默认15分钟
- 偏好风格？默认科技蓝白
- 已有数据？如跟单率3.5%→8%
- 竞品信息？
- 特殊要求？

→ 用户回复"开始"或直接提供部分信息
```

## AI 自动推断项

以下信息 **不需要用户提供**，AI 自动推断：

| 推断项 | 推断依据 |
|--------|---------|
| 行业背景 | 从用户输入中提取行业关键词，补充趋势和背景 |
| 市场数据 | 基于行业常识补充关键数据（规模、增长率） |
| 时间限制 | 默认15分钟，根据对象类型调整（CEO=10分钟，评审=20分钟） |
| 汇报策略 | 基于对象类型自动匹配 |
| 设计风格 | 基于对象+行业自动匹配（金融→黑金，技术→科技蓝白） |
| 输出格式 | 默认PPTX+HTML |

---

## 输出格式

```
【Discovery 结果】
- 汇报对象：[类型 + 自动推断的画像]
- 汇报目的：[类型 + 自动推断的故事线倾向]
- 核心输入：[用户原始输入]
- 用户额外提供：[可选信息中用户主动填写的内容]
- AI推断：
  - 行业背景：[自动补充]
  - 时间限制：[自动推断]
  - 汇报策略：[自动推断]
  - 设计风格：[自动推荐]
- 缺失信息：[列出需要AI补全的内容]
→ 触发 Content Expansion
```

## 过渡引导

完成后，告诉用户：

> "我已经理解了你的需求。接下来，我会基于你的输入，结合行业经验、案例和最佳实践，帮你补全一个完整的商业故事。你只需要确认方向是否正确，不需要逐一填写细节。"

然后自动进入 Content Expansion。
