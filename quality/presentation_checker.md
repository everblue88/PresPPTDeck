# Presentation Quality Checker — 汇报质量检查器

## 定位

> **在生成最终PPT之前和之后，自动检查汇报质量，确保三层评分均≥80分。**

## 检查流程

```
Full Content Approval → 质量检查 → 通过（三层均≥80分）→ 生成PPT
                                    → 不通过 → 返回优化 → 重新检查
```

---

## 一、三层评分体系

### 综合评分公式

```
综合得分 = Content Score × 0.4 + Slide Score × 0.35 + Design Score × 0.25
综合通过线：80分
```

---

## 二、Content Score（内容质量，40%权重）

### 评分维度

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 五层结构完整 | 战略层/目标层/方案层/执行层/价值层 | 25 |
| 有背景 | 行业趋势、市场变化、竞争格局 | 20 |
| 有方法 | 策略、路径、方案、关键决策 | 20 |
| 有价值 | 业务价值三维度（对业务/对组织/对未来） | 20 |
| 有未来规划 | 下一步、目标、资源需求 | 15 |

**通过线：80分**

### 五层结构检查清单

```
□ 战略层：说明了为什么做？（背景、趋势、行业变化）
□ 目标层：说明了想达到什么？（目标、价值主张）
□ 方案层：说明了准备怎么做？（路径、方法、策略）
□ 执行层：说明了具体做了什么？（案例、动作、成果）
□ 价值层：说明了产生了什么价值？（业务成果、组织能力、未来规划）
```

### 业务价值三维度检查

```
□ 对业务：带来什么？（增长/收入/活跃/转化）
□ 对组织：带来什么？（效率提升/能力沉淀/人才培养）
□ 对未来：形成什么？（新能力/新产品/新商业模式）
```

---

## 三、Slide Score（页面质量，35%权重）

### 评分维度

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 一个核心观点 | 每页只讲一件事，标题不含"和/与/及" | 20 |
| 标题观点化 | 标题表达观点，不是描述主题 | 20 |
| 副标题解释 | 解释标题的意义，补充视角 | 15 |
| 视觉表达 | 使用了合适的图形/图表/卡片 | 25 |
| 页面利用率≥60% | 内容覆盖面积达标 | 20 |

**通过线：80分**

### 逐页检查清单

```
□ 标题是否表达了观点？（不是"XX介绍"、"XX分析"）
□ 副标题是否解释了标题的意义？
□ 是否有核心逻辑句？（这一页想让听众记住什么）
□ 是否使用了合适的图形表达？（连续≥3条Bullet已转换）
□ 页面内容是否覆盖了≥60%的区域？
□ 是否命中空洞页面模式？（标题+三句话/纯列表/无数据）
```

### 空洞页面检测

```
□ 模式A：只有标题+三句话 → 返回Content Expansion
□ 模式B：纯列表>3条Bullet → 转换为图形化表达
□ 模式C：只有定性描述，无量化数据 → 补充数据或行业对标
```

---

## 四、Design Score（视觉质量，25%权重）

### 评分维度

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 风格统一 | 全篇使用同一设计风格 | 30 |
| 颜色统一 | 配色不超出风格定义，每页≤4种颜色 | 25 |
| 布局合理 | 元素对齐、间距一致、视觉层级清晰 | 25 |
| 避免模板感 | 不是套模板，页面之间有设计变化 | 20 |

**通过线：80分**

### 视觉一致性检查

```
□ 配色统一：全篇使用同一种设计风格
□ 字体统一：全篇标题/正文/注释使用统一字体
□ 图标统一：图标风格一致
□ 间距统一：页边距、卡片间距、行间距一致
□ 每页配色不超过4种颜色（不含黑白灰）
□ 强调色只用于关键数据或行动号召
```

## 六、快速检查清单（生成前最后确认）

```
□ 五层结构完整（战略/目标/方案/执行/价值）
□ 每页三段式表达（标题观点化+副标题解释+核心逻辑）
□ 每页只有一个核心观点
□ 每页内容元素≥5个
□ 没有空洞页面（标题+三句话/纯列表/无数据）
□ 连续≥3条文字已转换为图形表达
□ 体现了业务价值三维度（对业务/对组织/对未来）
□ 经过 Full Content Approval 用户确认
□ 风格统一（配色、字体、图标一致）
□ Content Score ≥80 | Slide Score ≥80 | Design Score ≥80
□ 综合得分 ≥80
```
