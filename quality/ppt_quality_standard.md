# PresPPTDeck PPT生成质量标准 V1.0

> **PresPPTDeck 生成的PPT必须满足：先有完整商业故事，再有页面表达；每一页必须有明确观点、充分内容、合适视觉表达，并通过质量检查后才能输出。**

---

## 核心原则：先构建故事，再生成页面

### ❌ 错误模式

```
用户输入几个关键词 → AI直接生成PPT页面 → 套模板美化
```
结果：内容空洞、页面像宣传页、缺少业务逻辑。

### ✅ PresPPTDeck模式

```
用户碎片信息 → AI理解业务背景 → 补充行业知识 → 构建完整故事线 → 确认PPT框架 → 设计页面表达 → 生成PPT
```

---

## 一、PPT整体必须满足"五层结构"

每一份PPT必须覆盖以下五个层级：

| 层级 | 核心问题 | 输出内容 |
|------|---------|---------|
| 战略层 | 为什么做？ | 背景、趋势、行业变化 |
| 目标层 | 想达到什么？ | 目标、价值主张 |
| 方案层 | 准备怎么做？ | 路径、方法、策略 |
| 执行层 | 具体做了什么？ | 案例、动作、成果 |
| 价值层 | 产生了什么价值？ | 业务成果、组织能力、未来规划 |

### 检查规则

- 五层结构是**内容完整性检查**，不是叙事顺序
- 叙事顺序使用6段式 Executive Story Framework
- 生成PPT后，逐层检查是否缺层

### 示例

```
普通：AI赋能产研

升级后：
战略层 → 金融行业进入AI生产力重构阶段
目标层 → 提升产研效率，沉淀核心能力
方案层 → AI工具 + AI Agent + AI产品三阶段
执行层 → AI剪辑、AI数字人、AI咨询落地
价值层 → 效率提升50%+，知识100%沉淀，新产品线
```

---

## 二、每一页PPT必须具备"三段式表达"

| 层级 | 名称 | 要求 | 反例 |
|------|------|------|------|
| Title | 页面标题 | **表达观点**，不是描述主题 | ❌"AI赋能" → ✅"AI赋能产研：从效率工具走向生产模式重塑" |
| Subtitle | 页面副标题 | **解释标题的意义** | ❌"提升效率" → ✅"通过AI提升个人效率、沉淀专家知识，并形成可持续的业务创新能力" |
| Key Message | 核心逻辑 | **这一页希望听众记住什么** | 必须是完整的一句话结论 |

---

## 三、One Slide One Message

> **一页只解决一个问题。**

**❌ 错误：** 一页同时讲AI、数据、APP、团队
**✅ 正确：** 拆成4页，每页一个主题

### 检查规则

- 每页标题只能包含一个核心观点
- 如果标题中有"和"、"与"、"及"，检查是否在讲两件事
- 如果一页的内容点可以分属两个不同主题，拆分

---

## 四、内容饱满度标准

### 4.1 页面内容密度

每页有效内容区域 **≥60%**。低于60%，自动触发 Content Expansion。

### 4.2 禁止空洞页面

以下三种情况必须重新设计：

**空洞模式A：只有标题+三句话**
```
❌ AI赋能 / 提高效率 / 创造价值
```
→ 必须升级为有数据、有案例、有行业对标的完整内容

**空洞模式B：纯列表（>3条连续Bullet）**
```
❌ 优化APP / 优化数据 / 优化AI / 优化流程
```
→ 必须转换为能力模型、Roadmap、飞轮模型等图形化表达

**空洞模式C：只有定性描述，无量化数据**
```
❌ 效率提升了
```
→ 必须补充具体数据或行业对标

### 4.3 每页内容元素最低要求

| 页面类型 | 最低内容元素 |
|---------|------------|
| 背景/趋势页 | ≥3个行业数据点 + ≥1个案例 |
| 问题/挑战页 | ≥3个具体痛点 + 数据量化 |
| 策略/方案页 | ≥3个策略，每个有做法+原因 |
| 数据/成果页 | ≥4个指标卡 + 基准对比 |
| 对比页 | ≥3组对比点 + 数据+洞察 |
| 规划页 | ≥3个阶段，每阶段≥2个目标 |

---

## 五、页面表达必须图形化

### 规则

> **连续超过3条文字，必须考虑视觉转换。**

| 文字内容 | 推荐表达 |
|---------|---------|
| 三个方向 | 三角模型 / 三卡片 |
| 发展规划 | Roadmap / 时间轴 |
| 流程变化 | 流程图 / 泳道图 |
| 前后变化 | Before/After |
| 能力建设 | 分层模型 / 金字塔 |
| 组织关系 | 组织架构图 |
| 数据结果 | Dashboard / 指标卡 |
| 问题分析 | 矩阵 / 四象限 |
| 增长逻辑 | 飞轮模型 |
| 技术方案 | 架构图 |

### 转换检查

- 每页生成前，检查连续Bullet数量
- ≥3条 → 触发 Pattern Selector 自动选择最佳视觉模式
- 如果无法找到合适的Pattern，考虑拆分页面

---

## 六、必须体现"业务价值"

金融企业尤其重要。不能只讲做了什么，必须回答三个问题：

### 对业务：带来什么？
- 增长（用户数、交易量、收入）
- 转化（获客、活跃、留存、付费）
- 效率（时间、成本、人力）

### 对组织：带来什么？
- 效率提升（流程优化、自动化）
- 能力沉淀（知识库、方法论、工具）
- 人才培养（团队成长、技能提升）

### 对未来：形成什么？
- 新能力（技术壁垒、产品矩阵）
- 新产品（可复制的产品线）
- 新商业模式（从成本中心到利润中心）

### 检查规则

- 每份PPT至少有1页明确回答"业务价值"三个维度
- 成果页必须包含"对业务"和"对组织"两个维度
- 规划页必须包含"对未来"维度

---

## 七、生成前必须经过Full Content Approval

AI先输出每页的完整内容（标题+副标题+核心逻辑+页面内容+来源标注），用户确认后再生成PPT。

**原因：避免一个错误故事被制作成漂亮PPT。**

---

## 八、生成后三层质量评分

### Content Score（内容质量）

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 五层结构完整 | 战略/目标/方案/执行/价值 | 25 |
| 有背景 | 行业趋势、市场变化 | 20 |
| 有方法 | 策略、路径、方案 | 20 |
| 有价值 | 业务价值三维度 | 20 |
| 有未来规划 | 下一步、目标、资源 | 15 |

**通过线：80分**

### Slide Score（页面质量）

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 一个核心观点 | 每页只讲一件事 | 20 |
| 标题观点化 | 标题表达观点，不是描述主题 | 20 |
| 副标题解释 | 解释标题的意义 | 15 |
| 视觉表达 | 使用了合适的图形/图表 | 25 |
| 页面利用率≥60% | 内容覆盖面积 | 20 |

**通过线：80分**

### Design Score（视觉质量）

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 风格统一 | 全篇使用同一设计风格 | 30 |
| 颜色统一 | 配色不超出风格定义 | 25 |
| 布局合理 | 元素对齐、间距一致 | 25 |
| 避免模板感 | 不是套模板，而是有设计思考 | 20 |

**通过线：80分**

### 综合评分

```
综合得分 = Content Score × 0.4 + Slide Score × 0.35 + Design Score × 0.25
综合通过线：80分
```

## 九、质量检查清单（生成前最后确认）

```
□ 五层结构完整（战略/目标/方案/执行/价值）
□ 每页三段式表达（标题观点化+副标题解释+核心逻辑）
□ 每页只有一个核心观点
□ 每页内容元素≥5个
□ 没有空洞页面（标题+三句话/纯列表/无数据）
□ 连续≥3条文字已转换为图形表达
□ 体现了业务价值三维度（对业务/对组织/对未来）
□ 经过 Full Content Approval 用户确认
□ 风格统一（配色、字体、图标一致）
□ Content Score ≥80 | Slide Score ≥80 | Design Score ≥80
```
