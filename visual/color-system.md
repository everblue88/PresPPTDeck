# Color System — 配色系统

## 默认基调（MBB Consulting + Executive）

- Background：White / #F5F7FA
- Primary：Navy（深蓝，标题与强调）
- Accent：Blue（行动项、链接、关键数字）

## 功能色（语义色，禁止乱用）

| 颜色 | 语义 |
|------|------|
| 绿色 | Validation / Success（验证、成功、达标） |
| 紫色 | Feedback / Revision（反馈、修订、待办） |
| 橙色 | Risk / Decision（风险、决策点、警示） |
| 灰色 | Secondary（辅助、次要信息） |

## 规则

1. 每页配色 ≤4 种（不含黑白灰）
2. 强调色只用于关键数据或行动号召，占比 ≤10%
3. 颜色必须承载语义，禁止随机配色

## 风格方案（按场景切换）

| 风格 | 主色 | 适用 |
|------|------|------|
| 科技蓝白 | #1A73E8 | AI / 技术 / 数字化 |
| 金融黑金 | #1A1A2E + #D4AF37 | 战略 / 高端汇报 |
| 极简白灰 | #FFFFFF + #1A1A1A | 产品 / 管理汇报 |
| 深色科技 | #0F172A + #38BDF8 | 发布会 / 技术峰会 |
| 活力橙红 | #FF6B35 | 产品发布 / 营销 |
