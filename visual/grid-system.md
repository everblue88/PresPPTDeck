# Grid System — 网格系统

## 基础

- 画布：16:9
- 网格：12-column grid

## 统一参数

| 参数 | 要求 |
|------|------|
| Margin | 统一页边距 |
| Gap | 统一间距 |
| Baseline | 统一基线 |
| Alignment | 统一对齐 |

## 规则

1. 所有元素对齐到网格
2. 卡片间距一致
3. 相邻页版式交替（左右 / 上下 / 居中 / 网格 / 三栏），全 deck ≥3 种
4. 每页只保留一个视觉重点

## 主从复合版式

每正文页 = 主 Exhibit（约 2/3）+ 侧栏（约 1/3）。
- 主层：核心图表/图形，带 Exhibit 连续编号 + 数据标签
- 侧栏：解读 / 辅证 / 口径，与主层平行阅读、不重复
