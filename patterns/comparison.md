# Pattern: Comparison（方案对比）

## 适用场景

- 多个方案/选项的对比分析
- 竞品对比、技术选型、策略选择

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ┌──────────┬──────────┬──────────┐      │
│  │ 维度     │ 方案A    │ 方案B    │      │
│  ├──────────┼──────────┼──────────┤      │
│  │ 成本     │ 低       │ 高       │      │
│  │ 时间     │ 3个月    │ 6个月    │      │
│  │ 风险     │ 中       │ 低       │      │
│  │ 效果     │ 好       │ 很好     │      │
│  ├──────────┼──────────┼──────────┤      │
│  │ 推荐     │          │   ★     │      │
│  └──────────┴──────────┴──────────┘      │
│                                          │
│  推荐理由：[一句话]                       │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 对比表 | 中部 | 3-4列，行数按需 |
| 推荐标记 | 表内 | 星标或高亮列 |
| 推荐理由 | 底部 | 14pt |

## 内容模板

```
标题：[对比主题]

对比维度：
  - 维度1：[名称]
  - 维度2：[名称]
  - 维度3：[名称]
  - 维度4：[名称]

方案A vs 方案B vs 方案C：
  [每个维度填充对比结果]

推荐方案：[方案名称]
推荐理由：[一句话]
```

## 使用示例

```
标题：获客渠道方案对比

对比维度：成本、覆盖范围、转化率、可持续性

渠道A：付费广告
  成本：高 | 覆盖：广 | 转化率：中 | 可持续：低

渠道B：内容营销
  成本：中 | 覆盖：中 | 转化率：高 | 可持续：高 ★推荐

渠道C：渠道合作
  成本：低 | 覆盖：窄 | 转化率：高 | 可持续：中

推荐：内容营销为主，渠道合作为辅
理由：长期可持续，转化率高，成本可控
```
