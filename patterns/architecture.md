# Pattern: Architecture（技术架构）

## 适用场景

- 展示技术架构、系统架构
- 技术方案评审、系统设计、平台架构

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ┌──────────────────────────────────────┐│
│  │          接入层                       ││
│  │  [Web] [App] [API] [SDK]            ││
│  └────────────────┬─────────────────────┘│
│                   │                      │
│  ┌────────────────┴─────────────────────┐│
│  │          业务层                       ││
│  │  [模块A] [模块B] [模块C] [模块D]     ││
│  └────────────────┬─────────────────────┘│
│                   │                      │
│  ┌────────────────┴─────────────────────┐│
│  │          数据层                       ││
│  │  [数据库] [缓存] [消息队列] [存储]   ││
│  └────────────────┬─────────────────────┘│
│                   │                      │
│  ┌────────────────┴─────────────────────┐│
│  │          基础设施层                    ││
│  │  [云服务] [容器] [监控] [安全]       ││
│  └──────────────────────────────────────┘│
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 架构图 | 中部 | 分层排列，从上到下 |
| 每层 | 矩形框 | 层名+组件列表 |
| 连接线 | 层之间 | 垂直箭头 |
| 组件 | 层内 | 小矩形，名称 |

## 内容模板

```
标题：[架构名称]

接入层：
  - [组件1]：[用途]
  - [组件2]：[用途]

业务层：
  - [模块1]：[功能]
  - [模块2]：[功能]
  - [模块3]：[功能]

数据层：
  - [存储1]：[用途]
  - [存储2]：[用途]

基础设施层：
  - [服务1]：[用途]
  - [服务2]：[用途]
```

## 使用示例

```
标题：AI赋能平台技术架构

接入层：
  - Web管理后台：运营人员使用
  - App SDK：集成到决策圈APP
  - Open API：对外开放接口

业务层：
  - AI客服引擎：智能问答
  - AI投研引擎：研报生成
  - AI知识引擎：知识沉淀
  - AI自动化引擎：流程自动化

数据层：
  - 知识图谱：业务知识存储
  - 模型仓库：AI模型管理
  - 数据湖：原始数据存储

基础设施层：
  - GPU集群：模型训练
  - K8s平台：服务部署
  - 监控告警：稳定性保障
```
