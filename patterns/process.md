# Pattern: Process（流程图）

## 适用场景

- 展示步骤、流程、操作链路
- 工作流程、技术流程、业务流程

## 结构图示

### 变体A：水平流程

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ┌──────┐   ┌──────┐   ┌──────┐   ┌────┐│
│  │ 步骤1 │──→│ 步骤2 │──→│ 步骤3 │──→│结果││
│  └──────┘   └──────┘   └──────┘   └────┘│
│   说明1      说明2      说明3      说明4  │
└──────────────────────────────────────────┘
```

### 变体B：垂直流程

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ┌──────────────────────────┐            │
│  │ 步骤1：名称               │            │
│  │ 说明                     │            │
│  └──────────┬───────────────┘            │
│             ↓                            │
│  ┌──────────────────────────┐            │
│  │ 步骤2：名称               │            │
│  │ 说明                     │            │
│  └──────────┬───────────────┘            │
│             ↓                            │
│  ┌──────────────────────────┐            │
│  │ 步骤3：名称               │            │
│  │ 说明                     │            │
│  └──────────────────────────┘            │
└──────────────────────────────────────────┘
```

### 变体C：泳道图

```
┌──────────────────────────────────────────┐
│  角色A  │ [步骤1] → [步骤3] → [步骤5]     │
│  ───────┼────────────────────────────── │
│  角色B  │    [步骤2] → [步骤4]            │
│  ───────┼────────────────────────────── │
│  角色C  │              [步骤6]            │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 流程节点 | 按方向排列 | 等间距 |
| 箭头 | 节点之间 | 粗箭头 |
| 节点说明 | 节点下方 | 12-14pt |

## 内容模板

```
标题：[流程名称]

步骤1：[名称]
  说明：[一句话描述]

步骤2：[名称]
  说明：[一句话描述]

步骤3：[名称]
  说明：[一句话描述]

步骤4：[名称]
  说明：[一句话描述]

结果/输出：[最终产出]
```

## 使用示例

```
标题：数据驱动业务：从数据到决策的完整链路

步骤1：数据采集
  从各业务系统采集原始数据

步骤2：数据清洗
  统一口径，清洗脏数据，建立数据链路

步骤3：指标计算
  按业务口径计算核心指标

步骤4：报表产出
  定期自动产出数据报表，支持业务分析

结果：数据覆盖全流程，让业务有据可依
```
