# Pattern: Cover（封面）

## 适用场景

- 任何PPT的首页
- 章节过渡页（变体）

## 结构图示

```
┌──────────────────────────────────────────┐
│                                          │
│           [装饰元素/品牌标识]              │
│                                          │
│                                          │
│           主标题（28-48pt）               │
│                                          │
│           副标题（16-20pt）               │
│                                          │
│         ──── 分隔线 ────                 │
│                                          │
│       汇报人  |  日期  |  部门            │
│                                          │
│                                          │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 大小 |
|------|------|------|
| 主标题 | 垂直居中偏上 | 36-48pt |
| 副标题 | 标题下方0.3英寸 | 16-20pt |
| 分隔线 | 副标题下方0.2英寸 | 宽2英寸，高0.03英寸 |
| 信息行 | 分隔线下方0.3英寸 | 13-15pt |
| 背景 | 全屏 | 纯色或渐变 |

## 内容模板

```
标题：[汇报主题，8-20字，有冲击力]
副标题：[一句话概括，可选]
汇报人：[姓名/部门]
日期：[YYYY年MM月]
```

## 变体

### 章节过渡页
- 标题改为章节名
- 增加章节序号（PART 01）
- 副标题改为章节描述

## 使用示例

```
标题：2025年度述职报告
副标题：产品驱动 · AI赋能 · 数据筑基
汇报人：产品经理 | 2025年度
```

## 视觉评分要点

- 标题有冲击力（不是"XX汇报"）
- 主标题字号足够大，视觉重心明确
- 信息层级清晰（标题 > 副标题 > 信息行）
