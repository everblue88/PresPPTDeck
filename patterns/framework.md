# Pattern: Framework（框架模型）

## 适用场景

- 表达战略框架、体系结构、能力模型
- 展示"组成部分"和"层次关系"

## 结构图示

### 变体A：三层架构

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│         ┌──────────────┐                 │
│         │   应用层      │  ← 业务场景     │
│         └──────┬───────┘                 │
│      ┌─────────┴─────────┐               │
│      │     中台层         │  ← 能力平台   │
│      └────────┬──────────┘               │
│   ┌───────────┴───────────┐              │
│   │      基础层            │  ← 基础设施  │
│   └───────────────────────┘              │
└──────────────────────────────────────────┘
```

### 变体B：三角模型（3个支柱）

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│              /\
│             /核心\
│            /──────\
│           /        \
│          /  支柱1   \  支柱2
│         /────────────\
│        /   支柱3      \
│       /────────────────\
│      /    基础支撑       \
│     /────────────────────\
└──────────────────────────────────────────┘
```

### 变体C：3卡片并列

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │ 方向一    │ │ 方向二    │ │ 方向三    │ │
│  │          │ │          │ │          │ │
│  │ 要点     │ │ 要点     │ │ 要点     │ │
│  │ 要点     │ │ 要点     │ │ 要点     │ │
│  └──────────┘ └──────────┘ └──────────┘ │
│          共同的战略目标                   │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 有观点的标题 |
| 架构图 | 中部 | 占页面55-65% |
| 说明文字 | 底部/侧边 | 每层简要说明 |

## 内容模板

```
标题：[战略/体系名称]

架构层：
  顶层：[名称] — [一句话说明]
  中层：[名称] — [一句话说明]
  底层：[名称] — [一句话说明]

或

三大支柱：
  支柱1：[名称] — [做什么]
  支柱2：[名称] — [做什么]
  支柱3：[名称] — [做什么]
```

## 使用示例

```
标题：AI赋能全流程：平台+场景双轮驱动

架构层：
  应用层：AI客服、AI风控、AI投研 — 3个业务场景
  中台层：AI模型平台、知识图谱、数据引擎 — 基础能力
  基础层：算力资源、数据治理、安全合规 — 基础设施
```

## 视觉评分要点

- 层级关系清晰，层次分明
- 每层不超过3个要点
- 使用不同颜色区分层级
- 说明文字简洁（每层不超过20字）
