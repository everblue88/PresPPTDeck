# Pattern: Case Card（案例卡片）

## 适用场景

- 展示客户案例、成功案例
- 用户证言、项目成果、行业标杆

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│  ┌──────────────────┐ ┌────────────────┐ │
│  │ [客户Logo/头像]   │ │ [客户Logo]     │ │
│  │                  │ │                │ │
│  │ "客户证言"        │ │ "客户证言"      │ │
│  │                  │ │                │ │
│  │ 客户名称          │ │ 客户名称        │ │
│  │ 行业 | 规模       │ │ 行业 | 规模     │ │
│  │ 核心成果          │ │ 核心成果        │ │
│  └──────────────────┘ └────────────────┘ │
│                                          │
│  ┌──────────────────┐                    │
│  │ [客户Logo]        │                    │
│  │ "客户证言"        │                    │
│  │ 客户名称          │                    │
│  └──────────────────┘                    │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 案例卡片 | 均匀分布 | 2-3个，等宽 |
| 卡片内 | 从上到下 | Logo → 证言 → 名称 → 成果 |

## 卡片模板

```
客户Logo/头像
"[客户证言，1-2句话]"
客户名称
行业 | 规模
核心成果：[数据]
```

## 内容模板

```
标题：[案例展示主题]

案例1：
  客户：[名称]
  行业：[行业] | 规模：[规模]
  证言："[客户原话]"
  核心成果：[关键数据]

案例2：
  ...

案例3：
  ...
```

## 使用示例

```
标题：AI赋能客户案例

案例1：某期货公司
  行业：期货 | 规模：中型
  证言："AI投研让我们的研报效率提升了3倍"
  核心成果：研报产出时间从3天缩短到1天

案例2：某证券营业部
  行业：证券 | 规模：大型
  证言："AI客服帮我们节省了40%的人力成本"
  核心成果：客服人力成本降低40%
```
