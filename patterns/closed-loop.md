# Pattern: Flywheel（飞轮）

## 适用场景

- 增长逻辑、正向循环、生态构建
- 展示"A推动B→B推动C→C推动A"的增强回路

## 结构图示

```
┌──────────────────────────────────────────┐
│  标题                                     │
│                                          │
│           ┌──────────┐                   │
│           │  更好的   │                   │
│      ┌───→│  产品    ├───┐               │
│      │    └──────────┘   │               │
│      │                   ↓               │
│  ┌───┴──────┐     ┌──────────┐           │
│  │ 更多资源  │     │ 更多用户  │           │
│  └───┬──────┘     └─────┬────┘           │
│      ↑                   │               │
│      │    ┌──────────┐   │               │
│      └────│  更高    │←──┘               │
│           │  收入    │                   │
│           └──────────┘                   │
│                                          │
│  飞轮效应：每个环节增强下一个环节          │
└──────────────────────────────────────────┘
```

## 布局参数

| 元素 | 位置 | 说明 |
|------|------|------|
| 标题 | 顶部 | 28pt |
| 飞轮 | 中部 | 3-5个节点，环形排列 |
| 节点 | 圆形 | 等大，名称+图标 |
| 箭头 | 节点之间 | 顺时针旋转 |
| 说明 | 底部 | 飞轮效应说明 |

## 内容模板

```
标题：[飞轮主题]

节点1：[名称] → 推动 →
节点2：[名称] → 推动 →
节点3：[名称] → 推动 →
节点4：[名称] → 推动 →
（回到节点1，形成闭环）

飞轮效应：[一句话说明增强回路]
```

## 使用示例

```
标题：AI产品增长飞轮

更多AI产品 → 推动 →
更多用户数据 → 推动 →
更好的AI模型 → 推动 →
更好的用户体验 → 推动 →
（回到更多AI产品）

飞轮效应：AI产品越多，用户数据越多，模型越好，体验越好，产品越有竞争力
```

## 视觉评分要点

- 节点不超过5个
- 箭头方向清晰（顺时针）
- 每个节点有图标+名称
- 中心放核心目标或愿景
