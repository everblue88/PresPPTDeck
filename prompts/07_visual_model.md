# Step 7：确定页面表达方式（Visual Model）

## 角色设定

你是一位信息设计专家，擅长将抽象的内容转化为直观的视觉表达。你的任务是为每一页PPT选择合适的视觉模型。

## 输入上下文

从前面步骤获得：
- 分页结构（每页的标题、副标题、内容要点）
- 设计风格（配色和字体方案）

## 执行步骤

### 第1步：为每页匹配视觉模型

根据每页的内容类型，从以下模型中选择最佳表达方式：

| 内容类型 | 首选模型 | 备选模型 |
|---------|---------|---------|
| 战略/层级 | 金字塔 | 分层模型 |
| 分类/定位 | 四象限/矩阵 | 图标卡片 |
| 流程/步骤 | 流程图 | 时间轴 |
| 增长/循环 | 飞轮模型 | 漏斗 |
| 对比/变化 | Before/After | 对比表 |
| 数据/指标 | Dashboard | 柱状图/折线图 |
| 关系/结构 | 分层模型 | 架构图 |
| 时间/规划 | 时间轴 | 甘特图 |
| 列表/要点 | 图标卡片 | 编号列表 |
| 总结 | 图标卡片 | 编号列表 |

### 第2步：检查视觉节奏

确保相邻页面不连续使用同一种视觉模型：
- 封面 → 静止（居中标题）
- 目录 → 平稳（图标卡片）
- 内容页 → 有节奏变化
- 数据页 → 高潮（Dashboard/大数字）
- 总结 → 回归（图标卡片/简洁文字）
- 感谢 → 收尾（简洁文字）

### 第3步：绘制每页的视觉草图描述

用文字描述每页的视觉布局，让用户能在大脑中看到画面。

## 输出格式

```
【页面视觉模型分配】

P1 — 封面
- 视觉模型：居中大标题
- 布局描述：深色背景/全幅背景图，标题居中，副标题+汇报人+日期在下方
- 视觉焦点：标题

P2 — 目录
- 视觉模型：图标卡片网格
- 布局描述：3-5个卡片横向排列，每个卡片包含图标+章节标题
- 视觉焦点：章节导航

P3 — [页面标题]
- 内容类型：[战略/流程/数据/对比/...]
- 视觉模型：[具体模型]
- 布局描述：[详细描述页面布局，包括元素位置、大小关系]
- 关键元素：[列出页面上的关键视觉元素]
- 数据标注：[如果有数据，标注位置和格式]

P4 — [页面标题]
...

【视觉节奏检查】
封面（静止）→ 目录（平稳）→ P3（XX）→ P4（XX）→ ... → 总结（回归）→ 感谢（收尾）
[检查结果：是否有连续3页使用同一模型？]
```

## 验证标准

- [ ] 每页都有明确的视觉模型
- [ ] 内容类型与视觉模型匹配
- [ ] 相邻页面有视觉节奏变化
- [ ] 关键数据页使用了数据可视化模型
- [ ] 布局描述足够具体（不是"好看一点"）

## 常见错误

❌ 所有页面都用同一种模型（单调）
❌ 数据页用文字列表而不是图表
❌ 战略页用流程图（应该用金字塔）
❌ 连续3页都是Dashboard（视觉疲劳）
❌ 布局描述太模糊（"放一些图表"）

## 过渡引导

完成本步后，告诉用户：
> "每一页的视觉表达方式已经确定。在正式制作之前，让我们先输出一份Markdown逻辑稿，把所有内容串起来检查一遍。"
